# Model selection

This candidate uses the later V16 base and V7 deck, rather than the stale
13-file package prepared before the final mounting revisions.

1. Base, with a 0.5 mm deep underside `Mendo by EQ Studio` engraving.
2. Fixed deck with integrated upper-shell feet and underside locating groove.
3. 15-compartment rotor gear.
4. 24-tooth pinion for the supplied servo horn.
5. MG996R cradle.
6. Direct-drop receiving cup.
7. 6 mm MT6701 adapter, 17 mm sensor and 28 mm deck hole spacing.
8. Screen frame with its inner window aligned to the base.
9. Four-hole 6 mm button back clamp.
10. Threaded dust-lid body.
11. Threaded dust-lid handle.
12. Upper shell.
13. Rounded upper-shell handle.

The deck has integrated feet: do not add the old loose four-foot set. Old board
edge clamp arrays and the one-piece dust lid are not this version's assembly.

STLs are source meshes, not printer profiles. Check orientation, material,
clearances and supports in your slicer. A combined 3MF is an object collection,
not a promise that all parts fit on one print plate. Engraving has not been
physically printed in this review. Preserve the original unbranded base as a
reference; only print one base.

OpenSCAD CAD uses the MCAD library shipped with OpenSCAD. Some older modules in
the source describe earlier assemblies; the STL list above defines this
candidate. The inherited name `as5600` in a CAD path is historical; this
prototype's sensor is MT6701.
